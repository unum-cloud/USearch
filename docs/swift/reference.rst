API Reference
===============

The Swift SDK is two files over the dense C surface: ``swift/Types.swift`` carries the shared
vocabulary of ``include/usearch/types.h``, and ``swift/DenseIndex.swift`` carries the dense
modality of ``include/usearch/dense_index.h``.

Doxygen does not read Swift, so the reference lives in the sources themselves as documentation
comments; ``docs/c/reference.rst`` documents the surface both files bind.
